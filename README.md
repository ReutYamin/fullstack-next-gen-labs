## הנחיות עבודה וגישה למעבדות

1. **קריאת המשימה במלואה מראש:** אין להתחיל בביצוע השלבים באופן אוטומטי. קראו את כל סעיפי המשימה, כולל הרקע והתוצרים הנדרשים, כדי להבין את תמונת המצב המלאה ואת מטרת הצינור (Pipeline) שאתם בונים.
2. **תכנון לפני כתיבה:** לפני שאתם רצים לכתוב קוד או YAML, שרטטו לעצמכם בצד או בראש את זרימת התהליך: מהו הטריגר (Event), איזה סוג שרת נדרש (Runner), ואילו שלבים (Steps) חייבים לקרות ובאיזה סדר.
3. **עבודה בשלבים מודולריים:** אל תנסו לבנות פייפליין שלם ומורכב בבת אחת. הקימו את הבסיס, בצעו Push, וודאו שהשרת עולה ומגיב. רק לאחר מכן הוסיפו את הצעדים הבאים בהדרגה.
4. **עצירה וניתוח בזמן כשל:** כשהפייפליין נכשל ונצבע באדום, זו לא שגיאה בקוד שלכם – זהו כלי הניטור שלכם שעובד. עצרו, קראו את הודעת השגיאה בקור רוח מההתחלה ועד הסוף, ורק אז גשו לתקן.
