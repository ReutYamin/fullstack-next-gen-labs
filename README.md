# FullStack Next-Gen Labs

ברוכים הבאים למאגר המעבדות והתרגולים הרשמי של קורס **FullStack Next-Gen**.

מטרת המאגר היא לרכז את כל ה־Lab Sheets שבהם נשתמש במהלך השיעורים. המעבדות נועדו לתרגל עבודה מעשית בתחומי הפיתוח, DevOps, GitHub Actions, Docker, CI/CD, Cloud וכלים מבוססי AI.

המעבדות אינן מיועדות לביצוע אוטומטי או להעתקה של פתרונות. מטרתן היא לפתח דרך חשיבה, יכולת תכנון, דיבאגינג ועבודה עצמאית.

## לפני שמתחילים

ודאו שיש ברשותכם:

* GitHub פעיל
* Git מותקן
* VSCode מותקן

ודאו שאתם יודעים לבצע:

* `git add`
* `git commit`
* `git push`

### הגדרת סביבת העבודה

במהלך המעבדות נעבוד על אותו Repository.

לפני תחילת המעבדה הראשונה צרו **Repository חדש ב-GitHub** ואתחלו אותו עם קובץ `README.md` בלבד.

לאורך המעבדות נוסיף יחד את כל הקבצים, התיקיות וההגדרות הנדרשות, כך שכולם יעבדו מאותה נקודת פתיחה ויעברו את אותו תהליך.

מאגר זה ישמש אותנו לאורך כל המעבדות.

## הנחיות עבודה

1. קראו את כל המעבדה לפני שאתם מתחילים לבצע את השלבים.
2. נסו להבין את מטרת המשימה לפני שאתם כותבים קוד.
3. עבדו בשלבים קטנים. לאחר כל שינוי בצעו Commit ובדקו שהתוצאה תקינה.
4. כאשר משהו נכשל, אל תמהרו לתקן. קראו את הודעת השגיאה, נסו להבין מה קרה ורק לאחר מכן חפשו פתרון.
5. השתמשו בכלי AI כחלק מתהליך העבודה, אך ודאו שאתם מבינים כל קטע קוד או YAML שאתם מוסיפים לפרויקט.
6. אם אתם נתקעים – שאלו שאלות. מטרת המעבדות היא ללמוד, להבין ולהתנסות, ולא רק להגיע לתוצאה הסופית.
